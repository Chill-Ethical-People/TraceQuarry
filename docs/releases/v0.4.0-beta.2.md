# TraceQuarry 0.4.0-beta.2

TraceQuarry 0.4.0-beta.2 expands the open-source Linux DFIR workbench from
single-collection parsing into a more durable case investigation workflow. The
release remains a public beta: use it for responder triage and timeline
reconstruction, then validate decisive findings against the original evidence.

## Highlights

- **Multi-collection case workspaces:** preserve per-host outputs while building
  a merged UTC timeline, case findings, IoC results, and conservative cross-host
  correlations.
- **Large-case intake:** stage up to 1,000 browser-selected files with bounded
  concurrent transfer, SHA-256 verification, retryable failures, and visible
  upload and parser state. The included UAT covers a 150-archive workflow.
- **Interactive evidence review:** filter the normalized timeline, inspect raw
  records and provenance, add analyst dispositions and tags, and promote pivotal
  events into a defensible reconstructed chronology.
- **Responder exports:** generate CSV and JSONL timelines, Markdown summaries,
  and a streamed XLSX investigation workbook with an executive briefing,
  selected chronology, complete timeline, and findings.
- **Broader Linux evidence:** ingest copied Linux log trees, individual and
  compressed rotated logs, and bounded read-only SQLite data, including
  extensionless Synology-style databases.
- **ATT&CK and detection content:** enrich timelines with confirmed and candidate
  MITRE ATT&CK phases using contributor-friendly YAML registries for TTPs,
  tooling, malware and payload signals, and non-attributive profile similarity.
- **Operational durability:** reopen completed cases from a SQLite case
  repository, recover interrupted state, observe job progress and readiness,
  and retain hash-chained analyst annotation history.
- **Security and provenance:** stream archive extraction safely, avoid
  materializing links and special members, enforce local evidence permissions,
  and preserve source hashes, coverage, timestamps, and parser errors.

## Looking Forward: CaseWeave

TraceQuarry now emits an experimental CaseWeave producer bundle for contract
testing. It is designed to preserve collection custody, immutable package
identity, evidence locators, normalized events, candidate findings, and omission
accounting. The CaseWeave importer and collaborative end-to-end workflow are
pending CaseWeave's public release and are not yet part of TraceQuarry's
supported public-beta feature set.
